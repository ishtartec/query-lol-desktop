What's inside

Champion Select — Builds

Auto-apply full rune pages, summoner spells, and item sets from OP.GG the moment you pick. Alternative builds with win/pick rates, color-coded skill order, and item/rune tooltips.

Drafting Intelligence

Pick & ban recommendations scored 0–100, per-enemy matchup win rates, team-composition callouts, all-lanes prediction, and a coach-style level-by-level plan for all 172 champions.

Live Game & Overlay

Real-time scoreboard, smurf detection, gold tracker, objective timers, win probability, MIA / death-timer / recall advisors, voice cues (TTS), and a hold-TAB in-game overlay.

Post-Game Analysis

Full scoreboard with MVP and multikill badges, gold-advantage timeline, elo comparison, and per-phase (early / mid / late) breakdowns of CS/min, gold/min, and KDA.

Profile & Improvement

Daily summary, tilt gate after loss streaks, role-aware improvement priorities vs elo benchmarks, LP progress chart, and per-champion deltas against your own baseline.

Lightweight by design

A ~15 MB native binary built with Tauri (Rust) + React. No Overwolf, no Electron. Windows and macOS, 11 regions, all HTTP done locally in Rust.
